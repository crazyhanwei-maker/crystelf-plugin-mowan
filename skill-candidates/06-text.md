# 文本处理候选能力

文本类 Skills 适合内容审核、短句翻译、文本统计和摘要辅助。优先选择返回简洁、结果容易解释的接口。

## 推荐能力

| 能力 | 优先级 | 适合场景 |
| --- | --- | --- |
| 敏感词快速检测 | A | 对群消息、评论或用户输入做基础前置检查 |
| 短句翻译 | A | 翻译简单短句，减少大模型消耗 |
| 语言检测 | B | 判断文本语言，适合作为翻译或审核前置 |
| 文本摘要 | B | 把较长文本压缩成更适合群聊阅读的摘要 |
| 文本统计 | B | 统计字符、词、句、段落和行数 |

## 使用建议

- 敏感词检测只能作为辅助判断，不能完全替代人工审核或 AI 审核。
- 免费翻译接口更适合短句，不适合正式长文精翻。
- 摘要接口需要控制输入长度，避免把过长正文直接提交。
- 涉及用户内容时，应避免把隐私信息发送到不可信接口。

## 建议优先接入

1. 敏感词快速检测。
2. 短句翻译。
3. 语言检测。
4. 文本统计。
5. 文本摘要。
