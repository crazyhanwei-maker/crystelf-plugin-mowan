# 网络类候选能力

网络类 Skills 适合用来做站点核验、链路诊断、域名背景查询和基础安全判断。

## 推荐能力

| 能力 | 优先级 | 适合场景 |
| --- | --- | --- |
| IP 信息查询 | A | 查询 IP 或域名的地区、运营商、ASN、经纬度 |
| 域名 RDAP 查询 | A | 查询域名注册状态、注册局、域名服务器和更新时间 |
| DNS 解析 | A | 查询 A、AAAA、CNAME、MX、TXT 等记录 |
| 手机号归属地 | A | 查询中国大陆手机号省市和运营商 |
| ICP 备案查询 | A | 查询网站备案主体，适合站点背景核验 |
| WHOIS 查询 | A | 查询注册商、创建时间、到期时间和域名状态 |
| URL 状态检查 | A | 判断链接是否可访问，辅助排查接口或页面问题 |

## 使用建议

- 域名和 URL 类工具适合配合群管理的链接安全检查使用。
- DNS 和 IP 查询适合控制台诊断、站点排查和机器人问答。
- 手机号归属地只适用于公开规则能识别的信息，不应用于敏感个人信息收集。
- URL 状态只能说明“能不能访问”，不能代替内容审核。

## 可暂缓能力

- 微信域名状态查询：场景较窄，可按需接入。
- 我的 IP 查询：控制台已有运行环境信息时优先级较低。
- 非 JSON WHOIS 文本：字段不稳定，建议优先使用 RDAP 或结构化 WHOIS。
