# 社交和平台资料候选能力

这类 Skills 适合把公开平台资料转成群聊可读的信息卡片，例如项目资料、视频信息、直播状态和账号简介。

## 推荐能力

| 能力 | 优先级 | 适合场景 |
| --- | --- | --- |
| GitHub 仓库信息 | A | 查询项目简介、语言、Star、Fork、Issue、最新 Release |
| GitHub 用户信息 | A | 查询开发者资料、组织、地区、个人简介和公开项目 |
| B 站视频信息 | A | 解析 BV 号或 AV 号，展示标题、封面、UP 主、播放数据 |
| B 站直播间信息 | A | 查询是否开播、直播标题、人气和分区 |
| B 站用户信息 | B | 查询 UP 主资料、签名、等级和粉丝量 |

## 使用建议

- GitHub 能力适合技术群、插件目录和版本说明。
- B 站视频能力适合群聊链接解析和视频内容摘要前置。
- 直播状态适合做“主播开播了吗”这类问答。
- 返回字段可能较多，接入时应只保留标题、作者、链接、统计数据等关键内容。

## 可暂缓能力

- B 站投稿列表：适合订阅类功能，但普通问答频率较低。
- B 站评论：返回内容较多，且容易涉及不稳定或不适合展示的文本，默认不建议接入。
