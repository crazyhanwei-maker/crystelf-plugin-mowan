# 媒体处理候选能力

媒体类 Skills 主要用于图片文字识别、二维码识别、图片审核和链接卡片补充。当前 HTTP Skills 更适合“传入公网 URL，返回 JSON”的接口。

## 推荐能力

| 能力 | 优先级 | 适合场景 |
| --- | --- | --- |
| 图片 OCR | A | 识别图片中的文字，适合截图、公告、报错图片 |
| 二维码识别 | A | 从图片 URL 读取二维码内容 |
| 图片审核 | B | 识别不适合群内展示的图片内容，需要账号或密钥时不建议默认启用 |
| 站点 Logo 提取 | B | 给链接卡片补充站点图标 |
| 公开头像资料 | B | 适合资料卡补全，使用场景较窄 |

## 使用建议

- OCR 和二维码识别要求图片能被外部接口访问。
- 图片审核涉及敏感内容，建议只在明确配置后启用。
- 需要上传本地文件的接口不适合当前通用 HTTP Skills。
- 直接返回图片二进制的接口应交给专门的图片链路处理。

## 暂缓能力

- 需要 `multipart/form-data` 上传文件的 OCR 或审核接口。
- 只返回图片文件、不返回 JSON 的二维码生成或图片生成接口。
- 需要高权限密钥且无法限制访问范围的媒体接口。
