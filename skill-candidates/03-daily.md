# 日常查询候选能力

日常类 Skills 适合轻量问答、群聊互动和定时提示。优先选择结果简短、容易理解、对用户直接有用的接口。

## 推荐能力

| 能力 | 优先级 | 适合场景 |
| --- | --- | --- |
| 世界时间 | A | 查询不同时区当前时间，适合跨地区群聊 |
| 程序员历史上的今天 | A | 日常互动、技术群话题、定时推送 |
| 指定日期历史事件 | B | 查询某个日期发生过的技术事件 |
| 一言 | B | 轻互动、欢迎语、空闲发言 |
| 行政区域查询 | A | 城市、区县、坐标、行政编码查询，可配合天气和空气质量 |
| 每日新闻图 | C | 适合图片早报，但当前 HTTP Skills 更适合 JSON 返回 |

## 使用建议

- 世界时间和行政区域查询适合做其他工具的前置能力。
- 历史上的今天适合技术群，不建议当成严肃新闻来源。
- 一言更偏娱乐，建议默认低优先级。
- 图片类早报需要额外的图片发送链路，不建议作为普通 HTTP Skill 直接接入。

## 建议优先接入

1. 世界时间。
2. 行政区域查询。
3. 程序员历史上的今天。
4. 一言。
