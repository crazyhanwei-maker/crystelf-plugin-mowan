# 更多公开接口方向

这一页汇总一些适合后续扩展的公开资料接口方向。接入前仍需要确认接口稳定性、访问限制、返回字段和合规要求。

## 推荐方向

| 分类 | 推荐能力 | 适合场景 |
| --- | --- | --- |
| 空气质量 | PM2.5、PM10、臭氧、AQI | 天气扩展、健康提醒、城市查询 |
| 地理信息 | 城市坐标、海拔 | 给天气、空气质量和路线类工具做前置 |
| 开源安全 | CVE、开源包安全风险 | 技术群、开发者工具、依赖风险查询 |
| 开发者资料 | npm、PyPI、Stack Overflow、Hacker News | 查包信息、技术问答、热门技术新闻 |
| 化学资料 | 化合物、分子式、分子量 | 科普问答、学习辅助 |
| 食品资料 | 条形码食品、品牌、营养等级 | 日常查询、健康饮食辅助 |
| 英文词典 | 释义、音标、例句 | 英语学习和短句解释 |
| 词语联想 | 同义词、押韵词、相关词 | 写作辅助和轻互动 |
| 动漫资料 | 动漫、角色、评分、年份 | 动漫群问答 |
| 游戏折扣 | PC 游戏折扣、历史低价 | 游戏群提醒 |
| 物种资料 | 物种分类、学名、分布记录 | 科普问答 |
| 学术资料 | 论文、DOI、作者机构 | 学术查询和资料检索 |
| 航天资料 | NASA 图片、自然事件、航天发射 | 科普和资讯 |
| 影视音乐 | 音乐人、专辑、剧集资料 | 娱乐问答 |
| 医疗健康资料 | 药品编码、召回、临床试验 | 只适合基础资料查询，回复必须提示仅供参考 |
| 趣味问答 | 冷知识、笑话、宝可梦资料 | 群聊互动 |

## 暂缓方向

这些方向不建议默认接入：

- 访问稳定性不足的接口。
- 强依赖账号或专用密钥的接口。
- 价格、金融、医疗、法律等高风险数据源。
- 返回内容过大且无法稳定裁剪的接口。
- 需要复杂授权、文件上传或多阶段轮询的接口。

## 建议下一批

如果要控制默认工具数量，建议优先考虑：

1. 空气质量。
2. 城市坐标和海拔。
3. 开源安全风险查询。
4. npm / PyPI 包信息。
5. 英文词典和相关词。
6. 动漫资料。
7. 游戏折扣。
8. 航天发射和 NASA 图片。

接入后建议在控制台中提供开关，让用户按自己的群聊场景决定是否启用。
