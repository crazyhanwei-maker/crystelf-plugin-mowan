Install Guide

安装使用

魔丸自带公益初始接口，安装后可以先体验基础 AI 能力。稳定使用时，再进入控制台换成自己的 API。

Quick Start

从安装到打开控制台

在 Yunzai 根目录安装，重启 Bot 后查看启动日志里的登录口令。控制台默认入口为 `http://127.0.0.1:27891/`。

01

首次启动

安装依赖后重启 Bot。第一次打开控制台时，按启动日志里的登录口令进入后台。

  • 确认插件位于 `plugins/crystelf-plugin`。
  • 运行 `pnpm install` 或 `npm install`。
  • 重启 Bot，让插件加载。
02

先体验公益接口

公益初始接口用于跑通基础体验，不需要一开始就准备完整模型服务。

  • 先测试 AI 对话、帮助和状态图。
  • 确认控制台页面能正常打开。
  • 长期使用建议替换成自己的 API。
03

逐步开启群能力

群管理和图片监控默认关闭，建议先选一个测试群开启。

  • 进入群管理页面选择目标群。
  • 先开启日志或提醒，再开启自动动作。
  • 危险操作前确认 Bot 权限和群规则。

Commands

常用群命令

当前插件实际命令仍以 `#灵晶` 开头。官网品牌叫魔丸，但命令名不在这里擅自改动。

#灵晶帮助查看默认帮助
#灵晶状态获取 Bot 运行状态图
#今日AI用量查看今日 AI 用量图
#查看进程查看系统进程图（主人）
#杀死PID 1234结束指定进程（主人）
#灵晶 功能状态查看功能开关状态
#灵晶查看更新日志查看插件更新日志
#灵晶开启群管理开启本群群管理能力
#灵晶关闭群管理关闭本群群管理能力
#群总结获取本群总结
#更新灵晶拉取插件更新
