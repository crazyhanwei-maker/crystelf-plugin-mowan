表情包 API

配置远程表情包服务，以及本地表情包目录的读取方式

基础接入

表情包服务目前只需要维护一个基础地址，适合单独放一组。

表情包 API 地址
表情包服务的 API 基础地址
测试角色
用于测试远程 API 和本地目录解析的角色名。默认优先取已显式配置的表情角色；若仍是旧默认值 zhenxun，则回退到内置人设名，再回退到当前机器人昵称。
测试情绪
例如 happy / default / angry，也支持中文情绪词，会自动做一次情绪映射。
尚未测试
点击“测试发图链路”后，可看到远程图是否能取到、本地是否有兜底，以及最终会走哪条发送路径。
拉取数量
按当前测试角色和测试情绪，从远程 API 拉取指定张数并保存到本地目录，单次最多 20 张。
尚未拉取
点击“拉取到本地”后，会把远程表情图保存到“本地表情包目录/角色/情绪/”下，并显示每张图的来源地址与保存路径。

本地目录

支持绝对路径和相对路径。相对路径会按机器人运行目录解析。

启用本地表情包
关闭后不会读取本地目录，只使用远程表情包服务。
优先本地表情包
开启后先从本地目录选图；关闭时先走远程，失败后再回退本地。
本地表情包目录
支持两种结构：1) 目录/角色/情绪/图片 2) 目录/角色/图片。第二种结构兼容图片监控自动入库目录。
目录结构示例
标准结构 <baseDir>/角色名/happy/001.png <baseDir>/角色名/default/002.jpg 扁平结构 <baseDir>/角色名/001.png <baseDir>/角色名/002.jpg 扁平结构适合图片监控自动入库目录；此时不会按情绪分文件夹，而是按角色随机取图。
尚未扫描 
点击“扫描本地目录”后，可查看角色、情绪目录和图片数量。
