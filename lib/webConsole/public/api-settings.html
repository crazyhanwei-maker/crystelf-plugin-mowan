AI 主对话 API

这里决定机器人平时聊天用哪个 AI 服务。

基础接入

先把接口地址、密钥和模型填完整，再决定是否补工作模型或多模态模型。

API 基础地址 *
填写服务商给你的基础地址，通常到 /v1 结束，不要填完整的聊天接口路径。
API 密钥 *
填写服务商提供的密钥；页面会隐藏已保存的密钥内容。
文本模型 *
机器人日常聊天主回复优先使用这个模型。
工作模型
用于规划、记忆检索、总结、欢迎、头衔审核等后台任务；留空时复用文本模型。
多模态模型
需要让机器人理解图片时填写；不用图片能力可以留空。

超时

主对话超时先在这里调整；如果还是不稳，再去控制台设置里配更细的保底文案。

请求超时（毫秒）
机器人等待主对话回复的最长时间，默认 60 秒。

备用 API

主接口不可用时可供运行时切换使用；这里单独维护备用地址、密钥和模型。

启用主对话备用 API
默认关闭；开启后请补完整备用接口信息。
备用 API 基础地址
备用服务商的 OpenAI 兼容基础地址。
备用 API 密钥
备用服务商密钥；留空会保持已保存密钥。
备用文本模型
备用主回复模型。
备用工作模型
备用后台任务模型。
备用多模态模型
备用图片理解模型。

图像生成 API

这里决定生图和改图走哪个服务。

基础接入

先决定走 OpenAI、对话式生图还是即梦，再填写模型、地址和密钥。

图像生成模式
按你实际使用的生图服务选择；选错会导致测试失败。
图像模型
生图服务要求的模型名称。
API 基础地址
OpenAI 风格或对话式生图服务的地址。
即梦接口地址
只有选择即梦模式时才需要填写。
API 密钥
生图服务提供的密钥；如果服务不需要密钥可留空。
图像尺寸
不确定时选自动；需要固定比例时再选择具体尺寸。
图像质量
不同服务支持的质量选项不一样；测试失败时可先改回推荐值。
响应格式
推荐使用图片数据模式，插件会自动转换成可发送的图片。
背景模式
只有部分 OpenAI 风格生图服务支持；不确定时保持“不传”。

超时与保底

这里集中放图像生成的超时时间和失败/超时兜底文案，方便一起调。

请求超时（毫秒）
等待生图结果的最长时间，默认 60 秒。
失败保底文案
生图或改图失败时回复给用户；留空则使用通用失败提示。
超时保底文案
生图或改图等太久时回复给用户；留空则使用通用超时提示。

备用 API

生图主服务失败时可使用备用生图服务，模式、地址、密钥和模型都独立配置。

启用生图备用 API
默认关闭；开启后建议先在批量测试里验证备用服务。
备用图像生成模式
可与主生图模式不同。
备用图像模型
备用生图服务要求的模型名称。
备用 API 基础地址
OpenAI 风格或对话式生图备用地址。
备用即梦接口地址
只有备用模式选择即梦时才需要填写。
备用 API 密钥
备用生图服务密钥；留空会保持已保存密钥。

图片监控 API

这里决定群聊图片是否审核、是否保存为本地表情包（推荐使用小模型，不用担心费用，提示词等有缓存不怎么花钱）。

基础接入

这里放图片监控的主开关、视觉模型地址、密钥和模型名。

启用图片监控
开启后会分析群聊图片；是否保存表情包还要看下面的入库开关。
API 基础地址
用于识别图片内容的服务地址。
API 密钥
图片识别服务提供的密钥。
审核模型
图片识别使用的模型名称。

超时与保底

图片监控默认失败静默。只有这里填了文案，识别失败或超时才会发群提示。

识别超时（毫秒）
等待图片识别结果的最长时间，默认 30 秒。
失败提示文案
识别失败时回复给群里的提示；留空则不发提示。
超时提示文案
识别超时时回复给群里的提示；留空则不发提示。

备用 API

图片识别主服务不可用时可切换到备用视觉模型服务。

启用图片监控备用 API
默认关闭；开启后请填写备用识别地址、密钥和模型。
备用 API 基础地址
备用图片识别服务地址。
备用 API 密钥
备用图片识别服务密钥；留空会保持已保存密钥。
备用审核模型
备用图片识别模型名称。

本地保存与入库

控制审核预览图保存、表情包本地入库，以及只保存指定角色或关键词的图片。

保存审核预览图
开启后会保存一份本地预览图，日志里以后也能看到。
保存表情包图片
开启后，识别为表情包的图片会按角色或情绪保存到本地。
入库角色白名单
只保存这些角色相关的表情包；留空表示不按角色限制。
入库关键词白名单
只保存命中这些关键词的图片；会匹配角色名、标签和摘要。

审核策略

违规处置策略、风险阈值、群范围限制等审核行为参数。

违规处置策略
命中违规时的处置方式：recall 撤回消息并警告；warn 仅发警告；ignore 静默记录。
风险阈值
0-1 之间，模型给出的风险分超过此值才判定为违规。
监控引用消息中的图片
开启后会一并分析引用消息中携带的图片。
白名单群
只在这些群里启用监控；留空表示所有群都监控。
黑名单群
这些群完全跳过监控；优先级高于白名单。
单条消息最多审核张数
同一条消息含多张图时最多审核前几张；超过的忽略。
去重时间窗（毫秒）
在此时间窗内重复出现的相同图片只审核一次；0 表示不去重。

识别参数

传给图片识别模型的 temperature 与 system prompt，可按需自定义审核风格。

识别 temperature
图片识别 LLM 的温度参数，0-2 之间；越低输出越稳定。
识别 system prompt
自定义图片识别的 system prompt；留空使用内置默认值。

搜索工具 API

这里决定机器人能否联网搜索和读取网页内容。

基础接入

先决定是否启用联网搜索，再填写密钥和网页读取的提交/查询地址。

启用联网搜索
开启后，机器人可在需要时调用搜索工具。
搜索 API 密钥
搜索服务提供的密钥；如果你的搜索服务不需要密钥可留空。
搜索接口地址
用于提交搜索关键词并返回搜索结果的接口地址。
网页读取提交地址
用于把网页内容转成可读文本的提交地址。
网页读取状态查询地址
用于查询网页读取是否完成；系统会自动带上任务编号。

超时

搜索和网页读取共用这里的客户端等待超时。先调稳定性，再决定是否调结果长度等细项。

请求超时（毫秒）
等待搜索或网页读取完成的最长时间，默认 60 秒。

备用 API

网页读取服务不稳定时可准备一组备用提交/查询地址。

启用搜索备用 API
默认关闭；开启后备用网页读取地址会单独保存。
备用搜索 API 密钥
备用搜索或网页读取服务密钥；不需要密钥可留空。
备用搜索接口地址
主搜索接口失败时使用的备用搜索地址。
备用网页读取提交地址
备用网页转 Markdown 任务提交地址。
备用网页读取状态查询地址
备用网页读取状态查询地址。

表情包 API

这里决定表情包优先从远程服务取，还是优先从本地目录取。

基础接入

表情包服务目前只需要维护一个基础地址，适合单独放一组。

表情包 API 地址
远程表情包服务地址；关闭远程服务时可以留空。
启用表情包备用 API
默认关闭；远程主表情服务不可用时可使用备用地址。
备用表情包 API 地址
备用远程表情包服务地址。
测试角色
用于测试取图的角色名；不填时会优先使用当前配置或机器人昵称。
测试情绪
可填 happy、default、angry，也可以填中文情绪词。
尚未测试
点击“测试发图链路”后，可看到远程图是否能取到、本地是否有兜底，以及最终会走哪条发送路径。
拉取数量
按上面的角色和情绪拉取图片并保存到本地，单次最多 20 张。
尚未拉取
点击“拉取到本地”后，会把远程表情图保存到“本地表情包目录/角色/情绪/”下，并显示每张图的来源地址与保存路径。

本地目录

支持绝对路径和相对路径。相对路径会按机器人运行目录解析。

启用本地表情包
关闭后只从远程服务取图，不读取本地目录。
优先本地表情包
开启后优先用本地图片；关闭时先试远程，失败后再用本地图片。
本地表情包目录
支持“角色/情绪/图片”和“角色/图片”两种目录结构。
目录结构示例
标准结构 <baseDir>/角色名/happy/001.png <baseDir>/角色名/default/002.jpg 扁平结构 <baseDir>/角色名/001.png <baseDir>/角色名/002.jpg 扁平结构适合图片监控自动入库目录；此时不会按情绪分文件夹，而是按角色随机取图。
尚未扫描 
点击“扫描本地目录”后，可查看角色、情绪目录和图片数量。
