# crystelf-plugin

> 面向 Yunzai / TRSS-Yunzai 的多功能群聊插件，集 AI 对话、群聊互动、RSS、点歌、网页工具与本地控制台于一体。

`crystelf-plugin` 的目标不是单纯堆功能，而是把“群聊运营 + AI 增强 + 可视化运维调试”收敛到同一个插件里。  
你可以先把它当作常规群功能插件使用，再按需接入模型、联网搜索、网页正文抓取、TTS、表情策略和控制台调试能力。

## 核心特性

- 群聊能力：欢迎、验证、戳一戳、表情互动、消息回复、60 秒早报、RSS、点歌
- AI 能力：多轮对话、上下文管理、记忆、用户画像、图片理解、联网工具、TTS
- 表情能力：AI 主动表情包、表情 API 检测、本地表情目录优先、`emoji` 抑制
- 魔丸控制台：登录鉴权、配置管理、链路检测、日志查看、网页调试、文件浏览编辑
- 运维友好：支持锅巴配置、支持健康检查、支持插件内 `git pull` 更新链路

## 适合场景

- 想先补齐欢迎、互动、RSS、点歌等基础群功能
- 已有模型接口，准备给 Bot 增加对话、联网和多模态能力
- 需要一个能直接看状态、查日志、测接口、改配置的本地控制台
- 希望减少零散插件，把常用能力集中维护

## 安装

```bash
git clone --depth=1 https://gitee.com/nuesurwan/crystelf-plugin.git ./plugins/crystelf-plugin
```

在 `Yunzai` 根目录安装依赖：

```bash
pnpm install
```

或：

```bash
npm install
```

## 快速配置

1. 启动 Bot，确认插件正常加载
2. 优先通过锅巴或魔丸控制台完成配置
3. 如果启用 AI，至少补齐：
   - `ai.baseApi`
   - `ai.apiKey`
   - `ai.modelType`
4. `ai.baseApi` 推荐填写 OpenAI 兼容基地址：

```text
https://xx.xx.com/v1
```

不要填写到 `/chat/completions`。

## 魔丸控制台

插件内置本地 Web 控制台，用于配置管理、链路检查与问题排查。

- 默认入口：`http://127.0.0.1:27891/`
- 登录页：`http://127.0.0.1:27891/login.html`
- 首次使用必须先设置控制台登录口令
- 未登录自动跳转登录页
- 配置中的口令、密钥等敏感字段不会明文回传前端
- 支持只读模式
- 支持文件浏览编辑器与网页调试对话

### 安全建议

- 默认建议仅监听 `127.0.0.1`
- 如果使用 `0.0.0.0`，请务必先设置 `webConsoleToken`
- 公网暴露时建议开启 `webConsoleReadOnly`
- 控制台口令连续输错会触发限流

## AI 与工具链

当前插件支持把 AI 对话和外部工具联动起来：

- `search_web`：联网搜索
- `fetch_web_markdown`：网页正文抓取与 Markdown 转换
- `speak_text`：TTS 语音输出

针对“用户直接发一个 URL 让 AI 总结”的场景，当前已经支持优先直读正文，而不是先把整条链接误当作 `site:` 搜索条件。

## 配置分层

- `config/config.json`
  - 主开关、控制台、基础功能开关
- `config/ai.json`
  - AI、人设、人性化、表情策略
- `config/coreConfig.json`
  - 搜索、网页抓取、TTS、用量控制等工具配置

实际运行时通常以 `Yunzai/data/crystelf/` 下的运行时配置为准。  
长期维护建议优先使用锅巴或魔丸控制台，而不是直接手改插件默认文件。

## 更新插件

如果插件目录本身就是 Git 仓库，可以直接在插件目录执行：

```bash
git pull
```

也可以在 Bot 内使用：

```text
#更新灵晶
```
