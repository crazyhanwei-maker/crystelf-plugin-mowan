# crystelf-plugin

> 面向 Yunzai / TRSS-Yunzai 生态的多功能群聊插件，集群聊互动、AI 对话、联网工具、点歌、RSS、本地 Web 控制台与网页调试能力于一体。

`crystelf-plugin` 不是只堆一批分散的小功能，而是希望把“群内运营能力 + AI 能力 + 可视化运维排障”收敛到同一个插件里。  
你既可以把它当成一套常规群功能插件来用，也可以继续接入模型、搜索、网页正文读取、TTS 与控制台调试能力，逐步扩展成一套长期可维护的群聊工作台。

## 功能概览

### 1. 群聊基础能力

- 欢迎入群、验证与群内互动
- 戳一戳、表情互动、消息回复
- 60 秒早报、RSS 推送
- 点歌、音乐搜索与音乐卡片渲染

### 2. AI 增强能力

- 多轮对话与会话管理
- 人设、上下文、记忆与用户画像
- 图片理解与多模态输入
- 联网搜索与网页正文抓取
- TTS 语音能力
- AI 主动表情包与情绪表达控制

### 3. 本地 Web 控制台

- 登录鉴权与会话保护
- 插件配置可视化管理
- 日志查看与健康检查
- AI 链路调试与网页阅读测试
- 文件浏览与编辑
- 配置脱敏展示，避免前端直接看到真实密钥

### 4. 面向维护与排障

- 支持锅巴配置
- 支持网页调试沙箱
- 支持检测搜索、网页读取、表情 API、TTS 等链路状态
- 适合持续维护，而不只是一次性装完即走

## 适合什么场景

- 想先补齐欢迎、互动、RSS、点歌等基础群功能
- 已有模型接口，准备给 Bot 增加对话、联网和多模态能力
- 需要一个能直接看状态、查日志、测链路、改配置的控制台
- 希望尽量少装零散插件，把常用能力集中管理

## 快速开始

### 安装插件

```bash
git clone --depth=1 https://gitee.com/nuesurwan/crystelf-plugin.git ./plugins/crystelf-plugin
```

### 安装依赖

在 `Yunzai` 根目录执行：

```bash
pnpm install
```

或：

```bash
npm install
```

### 启动与基础配置

1. 启动 Bot，确保插件正常加载
2. 优先通过锅巴或本地 Web 控制台完成配置
3. 如果启用 AI，至少补齐：
   - `ai.baseApi`
   - `ai.apiKey`
   - `ai.modelType`
4. `ai.baseApi` 推荐填写 OpenAI 兼容基地址，例如：

```text
https://xx.xx.com/v1
```

不要填写到 `/chat/completions`。

## 推荐的使用方式

### 先跑基础功能

如果你现在只想先把插件挂起来，建议先启用：

- 欢迎 / 验证
- 戳一戳互动
- RSS
- 点歌
- 基础群聊回复

### 再逐步补齐 AI 能力

后续再按需补齐：

- `ai.*`：模型对话
- `coreConfig.tools.search.*`：联网搜索与网页正文读取
- `coreConfig.tools.tts.*`：语音能力
- `ai.memeConfig.*`：表情相关能力

## 本地 Web 控制台

插件内置本地 Web 控制台，用来做配置管理、链路检查与问题排查。

### 默认入口

- 控制台首页：`http://127.0.0.1:27891/`
- 登录页：`http://127.0.0.1:27891/login.html`

### 当前特性

- 未登录自动跳转登录页
- 首次必须先设置控制台口令
- 登录成功后才允许进入控制台
- 支持脱敏显示配置中的敏感字段
- 支持只读模式
- 支持公网访问场景下的安全提醒

### 安全建议

- 默认建议只监听 `127.0.0.1`
- 如果要改成 `0.0.0.0`，请先设置登录口令
- 公网暴露时建议开启 `webConsoleReadOnly`
- 控制台口令连续输错会触发限流

## 网页调试与 AI 链路

控制台内置网页调试能力，适合单独验证 AI 工具链，而不影响真实群聊数据。

可用于检查：

- 搜索接口是否可用
- 网页转 Markdown 是否正常
- TTS 是否正常
- 表情 API 是否可用
- 最终回复链路是否存在异常

针对“用户直接发一个 URL 让 AI 总结”的场景，当前已支持优先直读正文，而不是先把完整链接错误地当作 `site:` 搜索条件。

## 配置说明

常用配置文件分层：

- `config/config.json`
  - 主开关、控制台、基础功能开关
- `config/ai.json`
  - AI、人格、人性化、表情策略
- `config/coreConfig.json`
  - 搜索、网页读取、TTS、用量控制等工具配置

实际运行时，通常以 `Yunzai/data/crystelf/` 下的运行时配置为准。  
长期维护时，推荐优先使用锅巴或 Web 控制台管理配置，而不是直接手改插件目录内默认文件。
