# crystelf-plugin

面向 Yunzai / TRSS-Yunzai 的群聊增强插件。当前版本：`2.2.1`。

插件主要围绕 AI 对话、图像生成、HTTP Skills、群管理、图片监控、模拟调试、帮助 DIY、运行状态图和本地控制台展开。日常配置建议优先使用“魔丸控制台”，只有少量高级项再直接编辑 JSON。

## 功能概览

| 模块 | 主要能力 |
| --- | --- |
| AI 对话 | 多轮上下文、用户画像、好感度、RAG 知识库、工具调用、受控插件命令桥接、图片理解、语音和表情包回复 |
| AI 生图 | 支持 `gpt-image-2`、OpenAI 兼容接口、火山方舟 Agent Plan、SD WebUI（A1111/Forge）、对话式生图和旧即梦接口 |
| HTTP Skills | 天气、快递、热榜、网页解析、论文、汇率、网络诊断、动漫、游戏、航天、公共接口等 |
| 魔丸控制台 | 登录鉴权、总览、插件设置、API 设置、命令中心与桥接授权、Agent 工作台、主题、日志排查、文件编辑、依赖检查 |
| Bot 插件管理 | 已装插件扫描、Git 状态、插件目录、插件安装、插件删除到回收站 |
| 群管理 | 群选择、默认设置、加群申请、自动审核、欢迎、AI 欢迎、风控、URL 安检、刷屏检测 |
| 群运营 | 每日群总结、`#群总结`、群头衔申请、AI 审核头衔、群管理实时事件和日志 |
| 图片监控 | 独立视觉模型审核、可选本地入库、持久化 MD5 去重、表情包角色/关键词过滤、非表情包清理 |
| 模拟调试 | 类 QQ 群界面、文本/图片/语音/截图、戳一戳、回复、@、CQ 码、meme 消息段，并可经二次确认执行真实改图 |
| 帮助系统 | `#灵晶帮助` 分类帮助、Help DIY、图片帮助模式、默认帮助图美化 |
| 状态图 | `#灵晶状态` 图片化展示 Bot 状态、AI 用量、生图用量、控制台地址隐藏 |

## 安装

在 Yunzai 根目录执行：

```bash
git clone --depth=1 https://gitee.com/nuesurwan/crystelf-plugin.git ./plugins/crystelf-plugin
```

安装依赖：

```bash
pnpm install
```

或：

```bash
npm install
```

重启 Bot 后插件会自动加载。

## 更新

在插件目录执行：

```bash
git pull
```

或由主人在群里发送：

```text
#更新灵晶
```

更新控制台、群管理运行时、API 路由、模拟调试、图片监控等功能后，建议重启 Bot。

## 控制台

默认监听所有网卡，常用入口：

```text
http://127.0.0.1:27891/
```

`webConsoleHost` 默认是 `0.0.0.0`。启动时如果没有配置 `webConsoleToken`，会自动生成随机登录口令、写入运行配置，并在启动日志里显示“控制台登录口令”。控制台页面始终要求登录；公网暴露时请限制来源并尽快改成强口令。

| --- | --- |
| 总览 | `/index.html` |
| 插件设置 | `/plugin-settings.html` |

Windows 本地可运行：

```bat

```

这个脚本不会写死或打印默认口令，也不会自动开放防火墙。需要局域网访问时请手动确认监听地址、口令和防火墙规则。

## 安全默认

- 群管理、图片监控、自动撤回、自动禁言、自动踢人、自动通过加群申请默认关闭。
- 图片监控的本地入库默认关闭；关闭时不保存图片，只记录 MD5，相同图片不会重复调用视觉模型。
- URL 安全检查默认关闭，开启后支持白名单和本地缓存。
- LLM 插件命令桥接默认关闭且授权列表为空；新发现的插件命令不会自动授权，高权限命令默认要求同一用户二次确认。
- Agent 工作台默认关闭；分析与补丁建议使用 `plan` Agent。用户可另行开启受控写入，由内置 OpenCode `build` Agent 在明确授权且 Git 状态干净的仓库中创建或修改文件；终端命令、外部目录和自动批准始终禁用。
- 插件目录安装默认“仅克隆仓库”；如果手动选择安装依赖，会根据 `packageManager` 和锁文件选择 pnpm、npm 或 yarn，并使用 `--ignore-scripts`。
- 插件删除会移入 `plugins/.crystelf-plugin-trash`，不会直接硬删。
- 控制台 API 受登录校验、来源校验和防跨站请求保护。
- 日志排查会把脱敏后的日志片段交给已配置的 AI 服务分析，建议只在可信接口下使用。

## 本地检查

```bash
npm run check
```

该命令会依次检查编码、项目结构、配置一致性、控制台脚本、核心功能、图片渲染和控制台接口。只需要快速检查静态文件时，可以运行：

```bash
npm run check:quick
```
