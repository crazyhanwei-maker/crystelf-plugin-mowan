# crystelf-plugin

面向 Yunzai / TRSS-Yunzai 的群聊增强插件。当前版本：`2.0.1`。

插件主要围绕 AI 对话、图像生成、HTTP Skills、群管理、图片监控、QQ 群模拟器、帮助 DIY、运行状态图和本地控制台展开。日常配置建议优先使用“魔丸控制台”，只有少量高级项再直接编辑 JSON。

## 功能概览

| 模块 | 主要能力 |
| --- | --- |

| HTTP Skills | 天气、快递、热榜、网页解析、论文、汇率、网络诊断、动漫、游戏、航天、公共接口等 |
| 魔丸控制台 | 登录鉴权、总览、插件设置、API 设置、主题、日志排查、文件编辑、依赖检查 |

| 群管理 | 群选择、默认设置、加群申请、自动审核、欢迎、AI 欢迎、风控、URL 安检、刷屏检测 |
| 群运营 | 每日群总结、`#群总结`、群头衔申请、AI 审核头衔、群管理实时事件和日志 |
| 图片监控 | 独立视觉模型审核、本地图片预览、表情包入库、角色/关键词过滤、非表情包清理 |
| QQ 模拟器 | 类 QQ 群界面、文本/图片/语音/截图、戳一戳、回复、@、CQ 码、meme 消息段 |
| 帮助系统 | `#灵晶帮助` 分类帮助、Help DIY、图片帮助模式、默认帮助图美化 |
| 状态图 | `#灵晶状态` 图片化展示 Bot 状态、AI 用量、生图用量、控制台地址隐藏 |

## 安装

在 Yunzai 根目录执行：

```bash
git clone --depth=1 https://gitee.com/nuesurwan/crystelf-plugin.git ./plugins/crystelf-plugin
```

安装依赖：

```bash
pnpm install
```

或：

```bash
npm install
```

重启 Bot 后插件会自动加载。

## 更新

在插件目录执行：

```bash
git pull
```

或由主人在群里发送：

```text
#更新灵晶
```

更新控制台、群管理运行时、API 路由、模拟器、图片监控等功能后，建议重启 Bot。

## 控制台

默认监听所有网卡，常用入口：

```text
http://127.0.0.1:27891/
```

`webConsoleHost` 默认是 `0.0.0.0`。启动时如果没有配置 `webConsoleToken`，会自动生成随机登录口令、写入运行配置，并在启动日志里显示“控制台登录口令”。控制台页面始终要求登录；公网暴露时请限制来源并尽快改成强口令。

常用页面：

| 页面 | 路径 |
| --- | --- |
| 总览 | `/index.html` |
| 插件设置 | `/plugin-settings.html` |
| API 设置 | `/api-settings.html` |
| Bot 插件管理 / 插件目录 | `/bot-plugins.html` |
| 群管理 | `/group-management.html` |
| 图片监控 | `/image-monitor-center.html` |
| QQ 模拟器 | `/qq-simulator.html` |
| 对话测试 | `/sandbox-chat.html` |
| 文件编辑 | `/file-browser.html` |
| 依赖检查 | `/dependency-check.html` |

Windows 本地可运行：

```bat
启动控制台.cmd
```

这个脚本不会写死或打印默认口令，也不会自动开放防火墙。需要局域网访问时请手动确认监听地址、口令和防火墙规则。

## 安全默认

- 群管理、图片监控、自动撤回、自动禁言、自动踢人、自动通过加群申请默认关闭。
- URL 安全检查默认关闭，开启后支持白名单和本地缓存。
- 插件目录安装默认“仅克隆仓库”；如果手动选择安装依赖，会使用 `npm install --ignore-scripts`。
- 插件删除会移入 `plugins/.crystelf-plugin-trash`，不会直接硬删。
- 控制台 API 受登录校验、来源校验和防跨站请求保护。
- 日志排查会把脱敏后的日志片段交给已配置的 AI 服务分析，建议只在可信接口下使用。
